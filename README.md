# FitCollector 🥦

Сервіс для пошуку **найдешевшого білка та калорій** у польських магазинах (Biedronka, Stokrotka, Lidl) і складання **денного раціону за мінімальну ціну** під задані КБЖВ.

## Що вміє

- 📊 Таблиця продуктів із метриками:
  - 💰 zł за 100 г білка;
  - 💰 zł за 1000 ккал;
  - 💪 грамів білка за 1 zł;
  - 🔥 ккал за 1 zł.
- Фільтр по магазинах і сортування по будь-якій метриці.
- 🍱 Кнопка «Скласти раціон»: вводиш цільові ккал, мінімум білка, (опційно) максимум жирів/вуглеводів — сервіс через лінійне програмування (симплекс-метод, класична «задача про дієту» Стіглера) підбирає найдешевший набір продуктів. Наприклад, день на 1200 ккал / 90 г білка виходить приблизно за **10–13 zł**.

## Запуск

Потрібні Java 21 і Maven.

```bash
mvn spring-boot:run
```

Далі відкрий http://localhost:8080

## API

| Метод | Шлях | Опис |
|---|---|---|
| GET | `/api/stores` | Список магазинів |
| GET | `/api/products?store=Lidl&sort=pricePer100gProtein&order=asc` | Продукти з метриками. `sort`: `pricePer100gProtein`, `pricePer1000Kcal`, `proteinPerZloty`, `kcalPerZloty`, `pricePer100g`, `price`, `name` |
| POST | `/api/ration` | Скласти найдешевший раціон |

Приклад запиту раціону:

```bash
curl -X POST http://localhost:8080/api/ration \
  -H 'Content-Type: application/json' \
  -d '{"targetKcal":1200,"minProteinG":90,"maxFatG":null,"maxCarbsG":null,"stores":[],"maxGramsPerProduct":500}'
```

Відповідь містить список продуктів із грамами та ціною, а також підсумки: вартість дня, ккал, білки/жири/вуглеводи.

## База продуктів

`src/main/resources/products.json` — ручна база з орієнтовними цінами та КБЖВ (ціни в магазинах змінюються, особливо на акціях). Формат запису:

```json
{
  "id": "b-jogurt-naturalny",
  "name": "Jogurt naturalny 370 g",
  "store": "Biedronka",
  "category": "nabiał",
  "packagePriceZl": 1.55,
  "packageGrams": 370,
  "kcalPer100g": 61,
  "proteinPer100g": 4.4,
  "fatPer100g": 2.0,
  "carbsPer100g": 6.2
}
```

Додавай/редагуй записи під актуальні ціни — все інше (метрики, сортування, оптимізатор) перерахується автоматично.

## Як працює оптимізатор

Змінні — кількість кожного продукту (в одиницях по 100 г). Мінімізується сумарна вартість за умов:

- калорії ≥ ціль і ≤ ціль + 5 % (щоб раціон не «роздувався» дешевими калоріями);
- білок ≥ мінімум;
- жири/вуглеводи ≤ максимум (якщо задано);
- не більше N грамів одного продукту (за замовчуванням 500 г — для різноманітності).

Розв'язується симплекс-методом (`commons-math3`). Порції округлюються до 5 г, дрібніші за 15 г — відкидаються.

## Ідеї на майбутнє

- Імпорт цін з [Open Prices](https://prices.openfoodfacts.org/) та КБЖВ з [Open Food Facts](https://world.openfoodfacts.org/) за штрихкодом.
- Парсери акційних газеток (Biedronka/Lidl публікують акції щотижня).
- Мікронутрієнти (клітковина, кальцій, залізо) як додаткові обмеження.
- Розбивка раціону на прийоми їжі.
